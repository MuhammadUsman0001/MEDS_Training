## 📚 Training Curriculum

| Module | Topic | Duration |
|--------|-------|----------|
| **Module 1** | Development Environment, Shell & Git | Week 1 |
| **Module 2** | C Language for Hardware Engineers | Week 2 |
| **Module 3** | RISC-V Instruction Set Architecture | Week 3 |
| **Module 4** | SystemVerilog for Digital Design | Week 4 |

**Additional Workshops:**
- RISC-V Processor in a Day
- SystemVerilog Hands-on Tasks
- Onur Mutlu's Lectures Documentation

## 🚀 Getting Started

```bash
git clone https://github.com/MuhammadUsman0001/MEDS_Training.git
cd MEDS_Training
```

Navigate to any module directory for specific exercises and assignments.

---

## 🎯 Key Projects

| Project | Module | Description |
|---------|--------|-------------|
| **RISC-V Log Analyzer** | Module 1 | Shell-based tool for parsing simulation logs |
| **RISC-V Instruction Decoder** | Module 2 | C program decoding RV32I instructions |
| **RISC-V Processor** | Workshop | Full RISC-V processor implementation in a day |
| **Direct-Mapped Cache Controller** | Module 4 | Parameterized cache controller in SystemVerilog |
| **Synchronous FIFO Controller** | Module 4 | FIFO with full/empty/almost flags |
